# go-gtp5gnl Configuration Guide

## Overview

go-gtp5gnl requires system-specific kernel parameters to calculate proper netlink message sizes for communication with the gtp5g kernel module. These parameters must be configured before building or deploying the library.

## Quick Start

### Automatic Detection (Recommended)

Use the provided detection script to automatically generate the configuration:

```bash
cd go-gtp5gnl
./scripts/detect_kernel_params.sh > go-gtp5gnl.yaml
```

This will detect all required parameters from your running kernel and create a `go-gtp5gnl.yaml` configuration file.

### Verify Configuration

To verify that your configuration matches your current system:

```bash
./scripts/detect_kernel_params.sh --verify
```

## Configuration Parameters

The configuration file (`go-gtp5gnl.yaml`) contains four required parameters:

### 1. `page_size` - System Page Size

**What it is:** The memory page size used by your system's kernel.

**How to retrieve manually:**
```bash
getconf PAGESIZE
```

**Typical values:**
- `4096` - Most x86_64 systems (4KB pages)
- `8192` - Some ARM64 systems (8KB pages)
- `16384` - Some PowerPC systems (16KB pages)
- `65536` - Some specialized systems (64KB pages)

**Example:**
```yaml
page_size: 4096
```

---

### 2. `max_skb_frags` - Maximum SKB Fragments

**What it is:** The kernel configuration parameter `CONFIG_MAX_SKB_FRAGS` that determines the maximum number of fragments in a socket buffer.

**How to retrieve manually:**

**Method 1:** From kernel config file (most reliable)
```bash
grep CONFIG_MAX_SKB_FRAGS /boot/config-$(uname -r)
```

**Method 2:** From /proc/config.gz (if available)
```bash
zcat /proc/config.gz | grep CONFIG_MAX_SKB_FRAGS
```

**Method 3:** From kernel headers
```bash
grep "define MAX_SKB_FRAGS" /usr/src/linux-headers-$(uname -r)/include/linux/skbuff.h
```

**Typical values:**
- `16` - Older kernels (< 4.x)
- `17` - Modern kernels (5.x, 6.x) - **Most common**
- `18` - Some custom kernels
- `32`, `45` - High-performance custom kernels

**Default if not found:** Use `17` (most common for modern kernels)

**Example:**
```yaml
max_skb_frags: 17
```

---

### 3. `skb_overhead` - SKB Shared Info Overhead

**What it is:** The aligned size of `struct skb_shared_info` in the kernel. This is calculated as `SKB_DATA_ALIGN(sizeof(struct skb_shared_info))`.

**How to calculate manually:**

The formula is:
```
struct_size = 48 + (16 × max_skb_frags)
skb_overhead = (struct_size + 63) & ~63    # Align to 64-byte boundary
```

**Quick reference table:**

| max_skb_frags | struct_size | skb_overhead (aligned) |
|---------------|-------------|------------------------|
| 16            | 304         | 320                    |
| 17            | 320         | 320                    |
| 18            | 336         | 384                    |
| 32            | 560         | 576                    |
| 45            | 768         | 768                    |

**Calculation example for max_skb_frags=17:**
```
struct_size = 48 + (16 × 17) = 48 + 272 = 320
skb_overhead = (320 + 63) & ~63 = 383 & ~63 = 320
```

**Using C program to calculate:**
```bash
cat > /tmp/calc_skb.c << 'EOF'
#include <stdio.h>
int main() {
    int max_skb_frags = 17;  // Change this to your value
    int struct_size = 48 + (16 * max_skb_frags);
    int aligned = (struct_size + 63) & ~63;
    printf("skb_overhead: %d\n", aligned);
    return 0;
}
EOF
gcc -o /tmp/calc_skb /tmp/calc_skb.c && /tmp/calc_skb
```

**Example:**
```yaml
skb_overhead: 320
```

---

### 4. `nlmsg_hdrlen` - Netlink Message Header Length

**What it is:** The size of `struct nlmsghdr` (netlink message header).

**Value:** Always `16` bytes on Linux systems.

**How to verify (optional):**
```bash
echo '#include <linux/netlink.h>' | gcc -E -dM - | grep NLMSG_HDRLEN
```

**Example:**
```yaml
nlmsg_hdrlen: 16
```

---

## Complete Configuration Example

```yaml
# go-gtp5gnl Configuration File
# Auto-generated by detect_kernel_params.sh on 2025-11-28
# Kernel: 6.8.0-87-generic
# Architecture: x86_64

# System page size in bytes
page_size: 4096

# Maximum number of SKB fragments
max_skb_frags: 17

# SKB shared info overhead in bytes
skb_overhead: 320

# Netlink message header length in bytes
nlmsg_hdrlen: 16
```

## Calculated Values (Informational)

From the configuration above, the library calculates:

```
if page_size < 8192:
    base_size = page_size
else:
    base_size = 8192

nlmsg_good_size = base_size - skb_overhead
nlmsg_default_size = nlmsg_good_size - nlmsg_hdrlen
```

**For the example configuration:**
- `base_size = 4096` (since page_size=4096 < 8192)
- `nlmsg_good_size = 4096 - 320 = 3776`
- `nlmsg_default_size = 3776 - 16 = 3760`

## Deployment Across Different Systems

When deploying to different systems, you **must regenerate** the configuration file on each target system:

```bash
# On each target system:
cd go-gtp5gnl
./scripts/detect_kernel_params.sh > go-gtp5gnl.yaml

# Verify the configuration
./scripts/detect_kernel_params.sh --verify

# Rebuild the library
go build ./...
```

## Troubleshooting

### Detection Script Fails to Find CONFIG_MAX_SKB_FRAGS

If the script cannot find `CONFIG_MAX_SKB_FRAGS`:

1. **Install kernel headers:**
   ```bash
   sudo apt install linux-headers-$(uname -r)  # Debian/Ubuntu
   sudo yum install kernel-headers-$(uname -r) # RHEL/CentOS
   ```

2. **Check if /proc/config.gz exists:**
   ```bash
   zcat /proc/config.gz | grep CONFIG_MAX_SKB_FRAGS
   ```

3. **Use default value:** If all else fails, use `17` (most common for modern kernels)

### Netlink Message Errors

If you encounter errors like "message too long" or "invalid argument":

1. **Verify your configuration matches your system:**
   ```bash
   ./scripts/detect_kernel_params.sh --verify
   ```

2. **Regenerate configuration:**
   ```bash
   ./scripts/detect_kernel_params.sh > go-gtp5gnl.yaml
   ```

3. **Check kernel version compatibility:**
   ```bash
   uname -r
   # Ensure kernel >= 5.0.0-23 or >= 5.4
   ```

### Configuration File Location

The library looks for `go-gtp5gnl.yaml` in the following locations (in order):

1. Current working directory: `./go-gtp5gnl.yaml`
2. Library directory: `$GOPATH/pkg/mod/github.com/.../go-gtp5gnl/go-gtp5gnl.yaml`
3. System config: `/etc/go-gtp5gnl/go-gtp5gnl.yaml`

You can also override via environment variable:
```bash
export GTP5GNL_CONFIG=/path/to/custom/go-gtp5gnl.yaml
```

## Advanced: Manual Calculation

If you prefer to calculate values manually without the script:

### Step 1: Get PAGE_SIZE
```bash
getconf PAGESIZE
# Example output: 4096
```

### Step 2: Get CONFIG_MAX_SKB_FRAGS
```bash
grep CONFIG_MAX_SKB_FRAGS /boot/config-$(uname -r)
# Example output: CONFIG_MAX_SKB_FRAGS=17
```

### Step 3: Calculate SKB_OVERHEAD
```bash
# Using the formula: SKB_DATA_ALIGN(48 + (16 * max_skb_frags))
# For max_skb_frags=17:
# struct_size = 48 + (16 * 17) = 320
# skb_overhead = (320 + 63) & ~63 = 320
```

### Step 4: Set NLMSG_HDRLEN
```bash
# Always 16 on Linux
```

### Step 5: Create go-gtp5gnl.yaml
```yaml
page_size: 4096
max_skb_frags: 17
skb_overhead: 320
nlmsg_hdrlen: 16
```
